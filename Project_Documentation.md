# Student Performance Analytics System

## 1. Project Objective
The objective of this project is to analyze student academic performance using Python, NumPy, and Pandas.

## 2. Technologies Used
- Python
- NumPy
- Pandas
- CSV

## 3. Dataset Description
The dataset contains 15 sample student records with Student ID, Name, Department, Python marks, SQL marks, Maths marks, and Attendance.

## 4. Implementation
Pandas is used to read student data from the CSV file. NumPy is used to calculate total and average marks. Python functions are used to assign grades and determine pass or fail status. Pandas operations are used for overall and subject-wise analysis.

## 5. Key Features
- Calculates total and average marks.
- Assigns grades based on average marks.
- Determines Pass or Fail status.
- Calculates class average.
- Identifies highest and lowest totals.
- Calculates subject-wise averages.
- Displays the top three students.

## 6. Output Summary
- Total students: 15
- Class average: 72.13
- Highest total: 285
- Lowest total: 120
- Pass count: 13
- Fail count: 2
- Highest subject average: Maths (74.53)

Top three students: Asha, Priya, and Nisha.

## 7. Learning Outcomes
This project helped me practise CSV file handling, Python functions, conditional statements, loops, NumPy calculations, Pandas DataFrames, and basic data analysis.

## 8. Final Outcome
The system successfully processes the sample student dataset and generates a student performance report with grades, results, and performance statistics.
